# Portfólio de Lucimar Santos

Landing page pessoal para apresentar os links profissionais e facilitar o
contato com Lucimar Santos. A página usa fundo preto, cards de links à esquerda
e foto e contato à direita em telas maiores; em dispositivos móveis, o conteúdo
se adapta a uma única coluna.

## Estrutura

```text
.
├── index.html
├── manifest.json
├── css/
│   └── style.css
├── perfil.jpg
└── ícones e favicons
```

O HTML contém a estrutura e o conteúdo da página. Todos os estilos visuais ficam
em `css/style.css`, referenciado no `index.html`. Não é necessário Bootstrap.

## Personalização

Para adicionar ou alterar um link, edite os cards dentro do elemento
`<nav class="link-cards">` em `index.html`. Atualize o endereço, o título e a
descrição do card. A foto utilizada na página é `perfil.jpg`.

O Google Tag Manager está configurado no HTML com o contêiner
`GTM-PZTV3P8N`.
